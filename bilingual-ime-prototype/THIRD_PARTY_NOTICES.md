# Third-party notices

## web-pinyin-ime / Android PinyinIME dictionary

This project includes a transformed Chinese Pinyin dictionary from
[`dongyuwei/web-pinyin-ime`](https://github.com/dongyuwei/web-pinyin-ime).
That project documents the dictionary's origin as Android Open Source Project
PinyinIME data. The included data and its Apache License 2.0 text are in
`src/vendor/web-pinyin-ime/`.

## CC-CEDICT

This project includes an English-definition extract of CC-CEDICT, published by
MDBG. The original compressed source data is in `src/vendor/cc-cedict/`, and
the filtered application index is in `src/data/cedict-en.json`. The source and
adapted index are licensed under CC BY-SA 4.0; attribution and license details
are in `src/data/CC-CEDICT-NOTICE.md`.
